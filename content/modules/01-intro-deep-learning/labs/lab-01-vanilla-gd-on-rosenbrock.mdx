## Part 1 — Define the Rosenbrock Function and its Gradient

The Rosenbrock function is defined as $f(x, y) = (1 - x)^2 + 100(y - x^2)^2$. Its global minimum is at $(1, 1)$ where $f = 0$.

    """Rosenbrock (banana) function."""
    return (1 - x[0])**2 + 100 * (x[1] - x[0]**2)**2

def rosenbrock_grad(x):
    """Gradient of Rosenbrock."""
    dx = -2 * (1 - x[0]) - 400 * x[0] * (x[1] - x[0]**2)
    dy = 200 * (x[1] - x[0]**2)
    return np.array([dx, dy])

<Callout type="warning" title="Common Pitfalls">

- **Learning rate too large for Rosenbrock**: lr > 0.002 often causes divergence because the narrow valley has very different curvatures along its two axes. If your loss explodes to NaN, halve the learning rate.
- **Forgetting to store history**: Make sure your GD loop appends a *copy* of the current position (`x.copy()`) — otherwise the entire history array points to the same mutable object.
- **Momentum too high**: β = 0.99 on Rosenbrock can overshoot the valley walls. Start with 0.9 and increase carefully.

</Callout>
