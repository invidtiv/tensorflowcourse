def softmax(x, axis=-1):
    """Softmax using broadcasting."""
    x_max = tf.reduce_max(x, axis=axis, keepdims=True)
    x_shifted = x - x_max
    exp_x = tf.exp(x_shifted)
    return exp_x / tf.reduce_sum(exp_x, axis=axis, keepdims=True)

## Common Pitfalls

| Pitfall | Why It Happens | Fix |
|---------|----------------|-----|
| **`ValueError: operands could not be broadcast` on axis mismatch** | Shapes are compared right-to-left: `(3, 4)` + `(3,)` fails because the trailing `(3,)` matches the last axis of `(3, 4)` only if sizes agree — here it does. But `(4, 3)` + `(3, 1)` fails because `(3, 1)` != `(4, 3)` on the leading axis. | Always sketch shape alignment right-to-left before coding. Use `np.broadcast_shapes(a.shape, b.shape)` to preview the result shape without materializing the arrays. |
| **Column vector `(N,)` vs `(N,1)` confusion** | `np.mean(data, axis=0)` returns shape `(F,)` — a 1D array. Subtracting it from `(N, F)` works, but trying to subtract it from `(F, N)` silently produces the wrong shape. | Use `.reshape(-1, 1)` or `[:, np.newaxis]` to make the intent explicit. Verify with `print(mean.shape)` before broadcasting. |
| **In-place broadcasting with `+=` widens dtype silently** | `arr += scalar` on an int array truncates the result back to int, discarding fractional parts. This is especially confusing when normalizing integer pixel arrays. | Cast to float first: `arr = arr.astype(np.float32)` before any in-place arithmetic. |
| **Broadcasting `np.tile` vs `broadcasting` giving different memory peaks** | `np.tile(b, (N, 1))` materializes a full `(N, F)` array in memory. On large datasets this can cause OOM errors that pure broadcasting avoids entirely. | Benchmark both and prefer broadcasting. Only use `np.tile` when you need the repeated array as a standalone object (e.g., for fancy indexing). |
| **Forgetting `axis=0` in per-feature reductions** | `np.mean(data)` returns a scalar (mean of all elements). `np.mean(data, axis=0)` returns a `(F,)` vector of per-feature means. Mixing these up normalizes by the global mean, not the per-feature mean. | Always state the axis explicitly and validate the output shape: `assert mean.shape == (n_features,)`. |
