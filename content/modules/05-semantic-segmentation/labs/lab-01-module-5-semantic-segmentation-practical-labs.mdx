## Overview

Semantic segmentation assigns a class label to **every pixel** in an image, producing a dense output mask of the same spatial resolution as the input. Unlike image classification (one label per image) or object detection (one bounding box per object), segmentation captures precise object boundaries and enables applications such as autonomous driving lane detection, medical lesion delineation, and satellite land-cover mapping.

This module covers the four major families of segmentation architectures and their supporting techniques:

- **Fully Convolutional Networks (FCN)** — the first end-to-end trainable dense prediction network, converting VGG's fully-connected layers to convolutional ones and adding transposed convolutions for upsampling. FCN-8s introduces skip connections from pool3/pool4 to recover fine spatial detail.
- **U-Net and variants** — an encoder–decoder with symmetric skip connections that concatenate high-resolution encoder features with the corresponding decoder level. Widely used in medical imaging; extended to U-Net++, Residual U-Net, and Attention U-Net.
- **DeepLab and ASPP** — uses atrous (dilated) convolutions to enlarge the receptive field without reducing resolution, and Atrous Spatial Pyramid Pooling (ASPP) to capture multi-scale context. DeepLabV3+ adds a lightweight decoder that fuses low-level features for sharper boundaries.
- **Loss functions and post-processing** — Dice loss, IoU loss, Focal loss, and Tversky loss address class imbalance; CRF post-processing refines boundaries; morphological operations and connected-component filtering clean up noise; test-time augmentation and model ensembling boost final metrics.

By the end of this module you will be able to build, train, evaluate, and deploy all major segmentation architectures from scratch in TensorFlow/Keras.

## Common Pitfalls

| Pitfall | Why It Happens | Fix |
|---------|----------------|-----|
| **Resizing masks with bilinear interpolation** | Bilinear resizing on integer class-ID masks creates fractional values between class IDs at boundaries; after rounding, these become wrong class labels and introduce spurious boundary errors in the ground truth. | Always resize masks with `method='nearest'` (`tf.image.resize(mask, size, method='nearest')`); apply bilinear only to the RGB image. |
| **Applying image augmentation without matching mask transform** | Random horizontal flip or rotation applied to the image but not to the corresponding mask creates misaligned pairs; the network learns boundary locations that do not correspond to real object edges, and both loss and metrics degrade silently. | Bundle image and mask into a single `(image, mask)` tuple and apply identical geometric transforms by sharing the same random state or `tf.random.Generator` seed. |
| **Using sigmoid output for multi-class segmentation** | For `num_classes > 2`, sigmoid produces independent per-class probabilities that sum to more than 1; this breaks Dice loss (over-counts the intersection) and makes argmax unpredictable when multiple class probabilities exceed 0.5. | Use `activation='softmax'` for multi-class; reserve `activation='sigmoid'` for strictly binary segmentation with one output channel. |
| **Mask encoding mismatch: one-hot vs integer class IDs** | Passing one-hot `(B,H,W,C)` masks to `SparseCategoricalCrossentropy` (which expects `(B,H,W)` integer IDs) causes TF to broadcast the extra channel dimension and compute a numerically incorrect loss without raising an error. | Use `SparseCategoricalCrossentropy` with integer masks `(B,H,W)` or `(B,H,W,1)`; use `CategoricalCrossentropy` only with fully one-hot encoded `(B,H,W,C)` masks. |
| **Not normalizing image pixels before feeding to the model** | Training with uint8 `[0, 255]` inputs causes the convolutional pre-activations to overflow, producing NaN weights within the first few gradient steps; the model appears to train (loss prints) but all weights become `nan` after step 2. | Cast and scale: `image = tf.cast(image, tf.float32) / 255.0`; add `tf.debugging.assert_all_finite(image, "Image contains NaN/Inf")` as a pipeline guard. |
