# Module 9: Time Series and Sequence Prediction - Practical Labs

## Introduction

Time series forecasting is one of the most practically important applications of deep learning, spanning finance, energy, healthcare, and climate science. This module walks you through the full pipeline — from raw signal to production-ready model — in six progressive parts.

**Learning progression:**

1. **Stationarity and preprocessing** — Raw time series are rarely stationary. You learn to detect trends and seasonality (ADF test, ACF/PACF), then remove them via differencing, linear detrending, or seasonal decomposition before feeding data to a model.
2. **Windowing** — Neural networks require fixed-size inputs. Sliding-window construction turns a 1-D series into `(N, window_size, features)` tensors. Lab 2 covers univariate, multivariate, expanding, and rolling-statistic windows.
3. **1D CNN for forecasting** — Convolutional layers extract local temporal patterns with far fewer parameters than LSTM. Labs 3–4 benchmark a dilated WaveNet-style stack against the LSTM baseline.
4. **LSTM and attention** — Long Short-Term Memory cells carry information across hundreds of timesteps; the Bahdanau attention mechanism lets the decoder selectively focus on encoder outputs, improving performance on multi-frequency signals.
5. **Multi-step forecasting strategies** — Three production-grade strategies: Direct (one dense head per horizon step), Recursive (autoregressive roll-out), and Seq2Seq encoder-decoder. You benchmark all three on identical data splits.
6. **Anomaly detection** — Autoencoders learn the normal manifold; reconstruction error flags anomalies. Labs 6.1–6.2 cover the LSTM autoencoder and a Variational Autoencoder (VAE) with probabilistic thresholding.

## Module Scaffold

The code block below provides a **runnable starting scaffold** you can execute before any individual lab. It generates synthetic data, defines a temporal train/val/test splitter, a windowing helper, a baseline LSTM, and an MAE evaluator — all reused across labs.

```python
"""
Module 9 Scaffold — run once before any individual lab.
Covers: data generation, temporal split, windowing, baseline LSTM, MAE eval.
"""

import numpy as np
import pandas as pd
import tensorflow as tf
from sklearn.preprocessing import MinMaxScaler
from sklearn.metrics import mean_absolute_error
import warnings
warnings.filterwarnings("ignore")

np.random.seed(42)
tf.random.set_seed(42)

# ── 1. Synthetic multi-component time series ─────────────────────────────────
N = 2000
t = np.arange(N)
series = (
    50
    + 0.015 * t                                        # trend
    + 12 * np.sin(2 * np.pi * t / 365)                # annual seasonality
    +  3 * np.sin(2 * np.pi * t / 7)                  # weekly seasonality
    + np.random.normal(0, 2, N)                        # noise
)
print(f"Series shape: {series.shape}  mean={series.mean():.2f}  std={series.std():.2f}")

# ── 2. Temporal train / val / test split (NO shuffling) ──────────────────────
def temporal_split(data, train_frac=0.70, val_frac=0.15):
    n = len(data)
    t1 = int(n * train_frac)
    t2 = int(n * (train_frac + val_frac))
    return data[:t1], data[t1:t2], data[t2:]

train_raw, val_raw, test_raw = temporal_split(series)
print(f"Split sizes — train={len(train_raw)}, val={len(val_raw)}, test={len(test_raw)}")

# ── 3. Scale on training data only ───────────────────────────────────────────
scaler = MinMaxScaler()
train_scaled = scaler.fit_transform(train_raw.reshape(-1, 1)).flatten()
val_scaled   = scaler.transform(val_raw.reshape(-1, 1)).flatten()
test_scaled  = scaler.transform(test_raw.reshape(-1, 1)).flatten()

# ── 4. Sliding-window helper ─────────────────────────────────────────────────
def make_windows(data, window_size=60, horizon=1):
    X, y = [], []
    for i in range(len(data) - window_size - horizon + 1):
        X.append(data[i : i + window_size])
        y.append(data[i + window_size : i + window_size + horizon])
    X = np.array(X)[..., np.newaxis]   # shape: (N, window, 1)
    y = np.array(y)                     # shape: (N, horizon)
    if horizon == 1:
        y = y.squeeze(-1)               # shape: (N,)
    return X, y

WINDOW, HORIZON = 60, 1
X_train, y_train = make_windows(train_scaled, WINDOW, HORIZON)
X_val,   y_val   = make_windows(val_scaled,   WINDOW, HORIZON)
X_test,  y_test  = make_windows(test_scaled,  WINDOW, HORIZON)
print(f"Window shapes — X_train={X_train.shape}, y_train={y_train.shape}")

# ── 5. Baseline LSTM ─────────────────────────────────────────────────────────
from tensorflow.keras import layers, callbacks

def build_baseline_lstm(window_size, n_features=1, units=64):
    inputs = tf.keras.Input(shape=(window_size, n_features))
    x = layers.LSTM(units, return_sequences=False)(inputs)
    x = layers.Dropout(0.2)(x)
    outputs = layers.Dense(HORIZON)(x)
    model = tf.keras.Model(inputs, outputs)
    model.compile(optimizer="adam", loss="mse", metrics=["mae"])
    return model

model = build_baseline_lstm(WINDOW)
es = callbacks.EarlyStopping(patience=5, restore_best_weights=True)
history = model.fit(
    X_train, y_train,
    validation_data=(X_val, y_val),
    epochs=30, batch_size=64, callbacks=[es], verbose=0
)
print(f"Training stopped at epoch {len(history.history['loss'])}")

# ── 6. MAE evaluation (inverse-transformed) ──────────────────────────────────
y_pred_scaled = model.predict(X_test, verbose=0)
y_pred = scaler.inverse_transform(y_pred_scaled.reshape(-1, 1)).flatten()
y_true = scaler.inverse_transform(y_test.reshape(-1, 1)).flatten()
mae = mean_absolute_error(y_true, y_pred)
print(f"Baseline LSTM test MAE: {mae:.4f}")
```

## Common Pitfalls

| Pitfall | Why It Happens | Fix |
|---|---|---|
| Scaler fitted on full series before splitting | Global min/max leaks future distribution into training | Always call `scaler.fit()` on training slice only, then `transform` val and test |
| Random shuffle before temporal split | Destroys causal ordering; windows straddle train/test boundary | Use `shuffle=False` or an explicit index cut; shuffle only within the training set |
| Missing stationarity check before modeling | Trend and seasonality cause non-stationary inputs that confuse gradient descent | Run ADF test (`statsmodels.tsa.stattools.adfuller`) and difference or detrend until `p < 0.05` |
| `window_size` shorter than dominant period | Model cannot observe a full seasonal cycle, so it cannot learn the pattern | Plot ACF/PACF to identify dominant period; set `window_size >= 1 × period` |
| 2-D input passed to LSTM | LSTM requires `(samples, timesteps, features)`; a 2-D array causes a shape error | Add `[..., np.newaxis]` or `reshape(N, W, 1)` after windowing |

## Stretch Goals

1. **Temporal Fusion Transformer (TFT)** — Implement a TFT using the `pytorch-forecasting` library or a TensorFlow port. TFT uses gated residual networks and multi-head attention with interpretable variable-selection weights. Compare validation MAE and training time against the baseline LSTM on the same scaffold data.
2. **N-BEATS** — Build an N-BEATS stack (trend + seasonality blocks with backward/forward residual links). N-BEATS is purely feed-forward with no recurrence, yet matches or beats LSTM on many benchmarks. Measure parameter efficiency (params per MAE point).
3. **DeepAR probabilistic forecasting** — Wrap the LSTM head with a Gaussian output layer (predict `mu` and `log_sigma`) and train with negative log-likelihood loss. Plot 10th/50th/90th percentile prediction intervals and measure empirical coverage rate.
4. **Walk-forward cross-validation** — Replace the single temporal split with an expanding-window CV loop: train on `[0:t]`, validate on `[t:t+v]`, advance by `v`, repeat. Aggregate MAE mean ± std across folds to produce a statistically robust benchmark instead of a single split estimate.
