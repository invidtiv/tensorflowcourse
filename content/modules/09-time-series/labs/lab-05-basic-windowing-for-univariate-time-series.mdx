# Basic Windowing for Univariate Time Series

### Complete Implementation

```python
"""
Lab 2.1: Basic Windowing for Univariate Time Series
Topic: Creating Training Windows
"""

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import tensorflow as tf
from sklearn.preprocessing import MinMaxScaler

np.random.seed(42)
tf.random.set_seed(42)

# Generate Sample Time Series Data
def generate_sine_wave(n_points=1000, freq=0.1, noise_level=0.1):
    t = np.arange(n_points)
    signal = np.sin(2 * np.pi * freq * t)
    noise = np.random.normal(0, noise_level, n_points)
    return signal + noise

print("=" * 60)
print("STEP 1: Generating Sample Time Series")
print("=" * 60)
data = generate_sine_wave(n_points=1000, freq=0.02, noise_level=0.1)
print(f"Generated {len(data)} data points")

# Implement Sliding Window (NumPy)
print("\n" + "=" * 60)
print("STEP 2: Sliding Window Implementation (NumPy)")
print("=" * 60)

def create_windows_numpy(data, window_size, horizon=1):
    X, y = [], []
    for i in range(len(data) - window_size - horizon + 1):
        X.append(data[i:(i + window_size)])
        y.append(data[(i + window_size):(i + window_size + horizon)])
    return np.array(X), np.array(y)

window_size = 20
horizon = 1
X, y = create_windows_numpy(data, window_size, horizon)
print(f"Window size: {window_size}")
print(f"Horizon: {horizon}")
print(f"X shape: {X.shape}")
print(f"y shape: {y.shape}")

# TensorFlow Dataset Windowing
print("\n" + "=" * 60)
print("STEP 3: TensorFlow Dataset Windowing")
print("=" * 60)

def create_windows_tf(data, window_size, horizon=1, batch_size=32, shuffle=True):
    dataset = tf.data.Dataset.from_tensor_slices(data)
    dataset = dataset.window(window_size + horizon, shift=1, drop_remainder=True)
    dataset = dataset.flat_map(lambda x: x.batch(window_size + horizon))
    dataset = dataset.map(lambda x: (x[:window_size], x[window_size:]))
    if shuffle:
        dataset = dataset.shuffle(buffer_size=1000)
    dataset = dataset.batch(batch_size).prefetch(tf.data.AUTOTUNE)
    return dataset

tf_dataset = create_windows_tf(data, window_size=20, horizon=1, batch_size=32)
print("TensorFlow Dataset structure:")
for batch_x, batch_y in tf_dataset.take(1):
    print(f"Batch X shape: {batch_x.shape}")
    print(f"Batch y shape: {batch_y.shape}")

# Multi-Horizon Windowing
print("\n" + "=" * 60)
print("STEP 4: Multi-Horizon Windowing")
print("=" * 60)

horizons = [1, 3, 7, 14]
for horizon in horizons:
    X_multi, y_multi = create_windows_numpy(data, window_size=20, horizon=horizon)
    print(f"Horizon {horizon}: X shape {X_multi.shape}, y shape {y_multi.shape}")

# Train-Validation-Test Split
print("\n" + "=" * 60)
print("STEP 5: Train-Validation-Test Split")
print("=" * 60)

def split_time_series(data, train_ratio=0.7, val_ratio=0.15):
    n = len(data)
    train_end = int(n * train_ratio)
    val_end = int(n * (train_ratio + val_ratio))
    train = data[:train_end]
    val = data[train_end:val_end]
    test = data[val_end:]
    return train, val, test

train_data, val_data, test_data = split_time_series(data)
scaler = MinMaxScaler()
train_scaled = scaler.fit_transform(train_data.reshape(-1, 1)).flatten()
val_scaled = scaler.transform(val_data.reshape(-1, 1)).flatten()
test_scaled = scaler.transform(test_data.reshape(-1, 1)).flatten()

X_train, y_train = create_windows_numpy(train_scaled, window_size, horizon)
X_val, y_val = create_windows_numpy(val_scaled, window_size, horizon)
X_test, y_test = create_windows_numpy(test_scaled, window_size, horizon)

print(f"X_train: {X_train.shape}, y_train: {y_train.shape}")
print(f"X_val: {X_val.shape}, y_val: {y_val.shape}")
print(f"X_test: {X_test.shape}, y_test: {y_test.shape}")

# Save data
np.save('/mnt/okcomputer/output/lab2_1_X_train.npy', X_train)
np.save('/mnt/okcomputer/output/lab2_1_y_train.npy', y_train)
np.save('/mnt/okcomputer/output/lab2_1_X_val.npy', X_val)
np.save('/mnt/okcomputer/output/lab2_1_y_val.npy', y_val)
np.save('/mnt/okcomputer/output/lab2_1_X_test.npy', X_test)
np.save('/mnt/okcomputer/output/lab2_1_y_test.npy', y_test)
import joblib
joblib.dump(scaler, '/mnt/okcomputer/output/lab2_1_scaler.pkl')
print("\nSaved windowed data for next labs")

print("\n" + "=" * 60)
print("Lab 2.1 Complete!")
print("=" * 60)
```

**Diagnostic tree — if you see something else:**

- `y_train.shape[0] != X_train.shape[0]` → off-by-one in the loop bounds. Stride should be `1`; loop range should be `len(data) - window_size - horizon + 1`.
- `X_train.shape[1] != 24` → window being flattened into feature axis by accident (e.g. using `data[i:i+W].flatten()` when data is already 1D — harmless here, but breaks when you add features later).
- All-zero or all-one scaled values → scaler fit on the full series instead of training-only. Refit on `train_data` alone.
- `X_val` or `X_test` shape is `(0, 24)` → the validation or test split is shorter than `window_size + horizon`. Either grow the split or shrink the window.

</Callout>

<Callout type="pitfall" title="Common Pitfalls">

- **Data leakage via scaler** — Fit `MinMaxScaler` on `train_data` only, then `transform` val and test. Fitting on the full series leaks future statistics (min/max) into training and inflates validation metrics.
- **Shuffling windowed data** — Once you have `(X, y)` pairs you *can* shuffle between samples (the temporal order within each window is preserved), but you must **not** shuffle the raw series before windowing. The latter destroys the signal entirely.
- **Window size unrelated to seasonality** — A 24-step window on hourly data captures one day, on daily data captures ~3 weeks. Check the ACF/PACF first and pick a window that covers at least one dominant seasonal period, or the model has no way to see it.
- **Horizon confusion** — `horizon=1` means "predict the next single step." To predict 5 steps ahead as a *single* target, use `horizon=5` with `y = data[i+W+H-1]` (direct). For a *sequence* of 5 predictions, `y` becomes 2D `(N, 5)` — a different problem (covered in lab-13).
- **Forgetting the `+1` in the loop bound** — `range(len(data) - window_size - horizon + 1)` is correct. Dropping the `+1` silently discards the last valid window; adding an extra one causes an `IndexError` on the final sample.
- **Hard-coded absolute paths** — `/mnt/okcomputer/output/...` works in this sandbox but breaks elsewhere. Prefer `pathlib.Path(__file__).parent / "output"` or a `OUTPUT_DIR` variable so the lab is portable.
- **Reusing a scaler across experiments** — If you change `train_ratio` or the data, the saved `scaler.pkl` is stale. Always re-fit or version the scaler alongside the model checkpoint.

</Callout>

## Common Pitfalls

| Pitfall | Why It Happens | Fix |
|---|---|---|
| Scaler fitted on full series before splitting | Global min/max leaks future statistics into the training distribution | Fit `MinMaxScaler` on `train_data` only; call `.transform()` on val and test slices |
| Shuffling the raw series before windowing | Destroys temporal ordering; windows no longer represent contiguous segments | Never shuffle the raw series; shuffle the `(X, y)` pairs only after windowing, and only within the training set |
| Window size unrelated to dominant period | A 24-step window on daily data covers only 3.4 weeks; annual seasonality is invisible to the model | Inspect the ACF plot for the dominant lag; set `window_size >= 1 × dominant period` |
| Horizon confusion between direct and sequential | `horizon=1` predicts one step; using `y = series[i+W+H-1]` for `H>1` changes to direct multi-step without signalling it | Define `horizon` explicitly and match the `y` construction to the intended strategy |
| Off-by-one in loop bound | `range(len(data) - W - H)` silently drops the last valid window | Use exactly `range(len(data) - W - H + 1)`; verify with a toy array of known length |
