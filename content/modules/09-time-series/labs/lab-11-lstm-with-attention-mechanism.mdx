# LSTM with Attention Mechanism

### Complete Implementation

```python
"""
Lab 4.2: LSTM with Attention Mechanism
Topic: Enhanced Time Series Prediction
"""

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.preprocessing import MinMaxScaler
from sklearn.metrics import mean_squared_error, mean_absolute_error

np.random.seed(42)
tf.random.set_seed(42)

# Prepare Data
print("=" * 60)
print("STEP 1: Preparing Data")
print("=" * 60)

def generate_data(n_points=1000):
    t = np.arange(n_points)
    trend = 0.01 * t
    seasonal = 10 * np.sin(2 * np.pi * t / 50)
    noise = np.random.normal(0, 2, n_points)
    return 100 + trend + seasonal + noise

data = generate_data(1000)
scaler = MinMaxScaler()
scaled_data = scaler.fit_transform(data.reshape(-1, 1)).flatten()

def create_windows(data, window_size, horizon=1):
    X, y = [], []
    for i in range(len(data) - window_size - horizon + 1):
        X.append(data[i:(i + window_size)])
        y.append(data[i + window_size])
    return np.array(X), np.array(y)

window_size = 60
X, y = create_windows(scaled_data, window_size, horizon=1)
X = X.reshape(X.shape[0], X.shape[1], 1)

train_size = int(0.7 * len(X))
X_train, y_train = X[:train_size], y[:train_size]
X_val, y_val = X[train_size:int(0.85*len(X))], y[train_size:int(0.85*len(X))]
X_test, y_test = X[int(0.85*len(X)):], y[int(0.85*len(X)):]
print(f"X_train: {X_train.shape}")

# Build Attention Layer
print("\n" + "=" * 60)
print("STEP 2: Building Attention Mechanism")
print("=" * 60)

class AttentionLayer(layers.Layer):
    def __init__(self, units):
        super(AttentionLayer, self).__init__()
        self.W1 = layers.Dense(units)
        self.W2 = layers.Dense(units)
        self.V = layers.Dense(1)
    
    def call(self, query, values):
        query_with_time_axis = tf.expand_dims(query, 1)
        score = self.V(tf.nn.tanh(
            self.W1(query_with_time_axis) + self.W2(values)
        ))
        attention_weights = tf.nn.softmax(score, axis=1)
        context_vector = attention_weights * values
        context_vector = tf.reduce_sum(context_vector, axis=1)
        return context_vector, attention_weights

# Build LSTM with Attention Model
print("\n" + "=" * 60)
print("STEP 3: Building LSTM with Attention Model")
print("=" * 60)

def build_attention_lstm(window_size, n_features=1):
    inputs = layers.Input(shape=(window_size, n_features))
    lstm_out, state_h, state_c = layers.LSTM(64, return_sequences=True, return_state=True)(inputs)
    attention_layer = AttentionLayer(64)
    context_vector, attention_weights = attention_layer(state_h, lstm_out)
    concat = layers.Concatenate()([context_vector, state_h])
    x = layers.Dense(32, activation='relu')(concat)
    x = layers.Dropout(0.2)(x)
    outputs = layers.Dense(1)(x)
    model = keras.Model(inputs=inputs, outputs=outputs)
    model.compile(optimizer='adam', loss='mse', metrics=['mae'])
    return model

model_attention = build_attention_lstm(window_size)
model_attention.summary()

# Train Model
print("\n" + "=" * 60)
print("STEP 4: Training Attention LSTM")
print("=" * 60)

early_stop = keras.callbacks.EarlyStopping(
    monitor='val_loss', patience=10, restore_best_weights=True
)

history = model_attention.fit(
    X_train, y_train,
    validation_data=(X_val, y_val),
    epochs=50,
    batch_size=32,
    callbacks=[early_stop],
    verbose=1
)

# Plot training history
plt.figure(figsize=(10, 4))
plt.plot(history.history['loss'], label='Train')
plt.plot(history.history['val_loss'], label='Validation')
plt.title('Training Loss')
plt.legend()
plt.grid(True, alpha=0.3)
plt.savefig('/mnt/okcomputer/output/lab4_2_attention_history.png', dpi=150)
plt.show()

# Evaluate
print("\n" + "=" * 60)
print("STEP 5: Evaluation")
print("=" * 60)

y_pred = model_attention.predict(X_test)
y_test_inv = scaler.inverse_transform(y_test.reshape(-1, 1)).flatten()
y_pred_inv = scaler.inverse_transform(y_pred).flatten()

mse = mean_squared_error(y_test_inv, y_pred_inv)
mae = mean_absolute_error(y_test_inv, y_pred_inv)

print(f"Test MSE: {mse:.4f}")
print(f"Test MAE: {mae:.4f}")

# Save model
model_attention.save('/mnt/okcomputer/output/lab4_2_attention_lstm.h5')

print("\n" + "=" * 60)
print("Lab 4.2 Complete!")
print("=" * 60)
```

The attention weights array (shape `(batch, window_size, 1)`) should show a peaked distribution — most weight concentrated on 1–3 recent timesteps for short-range patterns, or on periodic positions for seasonal data. A completely flat attention distribution (all weights ≈ 1/window_size) indicates the attention mechanism failed to learn discriminative alignment.

<Callout type="warning" title="Common Pitfalls">
1. **`query_with_time_axis` expansion axis** — `tf.expand_dims(query, 1)` must expand along axis 1 to broadcast across the `values` timestep dimension. Using axis 0 or -1 silently produces incorrect shapes that still compute without error but produce meaningless scores.
2. **Missing softmax normalisation** — if you omit `tf.nn.softmax(score, axis=1)` and use raw scores directly as weights, the context vector is an unnormalised weighted sum. Attention weights no longer sum to 1, losing their interpretability as a probability distribution over timesteps.
3. **Shared W_1/W_2 weights** — `self.W1` and `self.W2` must be separate `Dense` layers. If the same layer is reused for both query and values projection, the attention mechanism collapses into a scalar self-correlation, unable to distinguish the two inputs.
4. **Concatenation shape mismatch** — `context_vector` (shape `(batch, 64)`) and `state_h` (shape `(batch, 64)`) must both have 2D shapes for `layers.Concatenate()` to work. If `return_sequences=False` is not set for the second LSTM call, `state_h` has shape `(batch, timesteps, 64)` and concatenation raises a shape error.
5. **Dropout at inference** — ensure `Dropout(0.2)` uses `training=False` during `model.predict()`. Keras handles this automatically when using the `Dropout` layer (not a manual `tf.nn.dropout` call). Using manual dropout that is not conditioned on the training flag inflates inference-time variance and artificially inflates MAE.
6. **Deprecated `.h5` format** — `model.save('path.h5')` is deprecated in Keras 3. Prefer `model.save('path.keras')` to avoid a `DeprecationWarning` and future incompatibility with saved-model loading.
</Callout>

## Common Pitfalls

| Pitfall | Why It Happens | Fix |
|---|---|---|
| `tf.expand_dims` on wrong axis for query broadcast | Expanding along axis 0 or -1 instead of axis 1 produces a shape that broadcasts silently but computes wrong attention scores | Use `tf.expand_dims(query, 1)` (axis=1) so the query broadcasts across the `values` timestep dimension |
| Raw attention scores used without softmax normalisation | Without `tf.nn.softmax(score, axis=1)` the context vector is unnormalised; weights no longer sum to 1 and lose probabilistic interpretation | Always apply softmax over the time axis before computing the weighted sum |
| Shared `W1`/`W2` weight matrices | Reusing the same `Dense` layer for both query and values projection collapses the attention into a scalar self-correlation | Declare `self.W1` and `self.W2` as separate `Dense` layers in `__init__` |
| Flat attention distribution (all weights ≈ 1/T) | The attention layer did not converge — often caused by vanishing gradients or too-small learning rate on the attention parameters | Reduce `tanh` saturation by using `LeakyReLU` before the score projection; increase attention layer learning rate via a separate optimizer param group |
| Missing stationarity check before attention LSTM | Non-stationary input with a strong trend causes the attention to fixate on the most recent timestep regardless of frequency content | Difference or detrend the series until ADF `p < 0.05` before windowing and training |
