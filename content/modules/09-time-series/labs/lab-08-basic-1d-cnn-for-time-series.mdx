# Basic 1D CNN for Time Series

### Complete Implementation

```python
"""
Lab 3.1: Basic 1D CNN for Time Series
Topic: Stock Price Prediction with 1D CNN
"""

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers
from sklearn.metrics import mean_squared_error, mean_absolute_error
import joblib

np.random.seed(42)
tf.random.set_seed(42)

# Generate and Prepare Data
print("=" * 60)
print("STEP 1: Generating Stock Data")
print("=" * 60)

def generate_stock_data(n_days=1000):
    dates = pd.bdate_range(start='2020-01-01', periods=n_days)
    trend = np.cumsum(np.random.normal(0.001, 0.01, n_days))
    seasonal = 5 * np.sin(2 * np.pi * np.arange(n_days) / 252)
    prices = 100 + trend + seasonal + np.cumsum(np.random.normal(0, 0.5, n_days))
    return pd.DataFrame({'Close': prices}, index=dates)

stock_data = generate_stock_data(1000)
print(f"Generated {len(stock_data)} data points")

from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
scaled_data = scaler.fit_transform(stock_data[['Close']]).flatten()

# Create Windows
print("\n" + "=" * 60)
print("STEP 2: Creating Windows")
print("=" * 60)

def create_windows(data, window_size, horizon=1):
    X, y = [], []
    for i in range(len(data) - window_size - horizon + 1):
        X.append(data[i:(i + window_size)])
        y.append(data[i + window_size])
    return np.array(X), np.array(y)

window_size = 60
X, y = create_windows(scaled_data, window_size, horizon=1)
X = X.reshape(X.shape[0], X.shape[1], 1)

train_size = int(0.7 * len(X))
val_size = int(0.15 * len(X))
X_train, y_train = X[:train_size], y[:train_size]
X_val, y_val = X[train_size:train_size + val_size], y[train_size:train_size + val_size]
X_test, y_test = X[train_size + val_size:], y[train_size + val_size:]

print(f"X_train: {X_train.shape}")
print(f"X_val: {X_val.shape}")
print(f"X_test: {X_test.shape}")

# Build Basic 1D CNN Model
print("\n" + "=" * 60)
print("STEP 3: Building Basic 1D CNN Model")
print("=" * 60)

def build_basic_cnn(window_size, n_features=1):
    model = keras.Sequential([
        layers.Conv1D(filters=64, kernel_size=3, activation='relu',
                      padding='same', input_shape=(window_size, n_features)),
        layers.BatchNormalization(),
        layers.MaxPooling1D(pool_size=2),
        layers.Conv1D(filters=32, kernel_size=3, activation='relu', padding='same'),
        layers.BatchNormalization(),
        layers.MaxPooling1D(pool_size=2),
        layers.Conv1D(filters=16, kernel_size=3, activation='relu', padding='same'),
        layers.BatchNormalization(),
        layers.Flatten(),
        layers.Dense(50, activation='relu'),
        layers.Dropout(0.2),
        layers.Dense(1)
    ])
    model.compile(optimizer='adam', loss='mse', metrics=['mae'])
    return model

model_basic = build_basic_cnn(window_size)
model_basic.summary()

# Train Basic CNN
print("\n" + "=" * 60)
print("STEP 4: Training Basic CNN")
print("=" * 60)

early_stop = keras.callbacks.EarlyStopping(
    monitor='val_loss', patience=10, restore_best_weights=True
)
reduce_lr = keras.callbacks.ReduceLROnPlateau(
    monitor='val_loss', factor=0.5, patience=5, min_lr=1e-6
)

history_basic = model_basic.fit(
    X_train, y_train,
    validation_data=(X_val, y_val),
    epochs=50,
    batch_size=32,
    callbacks=[early_stop, reduce_lr],
    verbose=1
)

# Plot training history
fig, axes = plt.subplots(1, 2, figsize=(15, 5))
axes[0].plot(history_basic.history['loss'], label='Train Loss')
axes[0].plot(history_basic.history['val_loss'], label='Val Loss')
axes[0].set_title('Training Loss')
axes[0].legend()
axes[0].grid(True, alpha=0.3)
axes[1].plot(history_basic.history['mae'], label='Train MAE')
axes[1].plot(history_basic.history['val_mae'], label='Val MAE')
axes[1].set_title('Training MAE')
axes[1].legend()
axes[1].grid(True, alpha=0.3)
plt.savefig('/mnt/okcomputer/output/lab3_1_basic_cnn_history.png', dpi=150)
plt.show()

# Evaluate and Save
print("\n" + "=" * 60)
print("STEP 5: Evaluating Basic CNN")
print("=" * 60)

y_pred = model_basic.predict(X_test)
y_test_inv = scaler.inverse_transform(y_test.reshape(-1, 1)).flatten()
y_pred_inv = scaler.inverse_transform(y_pred).flatten()

mse = mean_squared_error(y_test_inv, y_pred_inv)
mae = mean_absolute_error(y_test_inv, y_pred_inv)
rmse = np.sqrt(mse)

print(f"Test MSE: {mse:.4f}")
print(f"Test MAE: {mae:.4f}")
print(f"Test RMSE: {rmse:.4f}")

# Save model
model_basic.save('/mnt/okcomputer/output/lab3_1_basic_cnn.h5')
joblib.dump(scaler, '/mnt/okcomputer/output/lab3_1_scaler.pkl')
print("\nModel saved")

print("\n" + "=" * 60)
print("Lab 3.1 Complete!")
print("=" * 60)
```

- `model.summary()` reports roughly **~10k–30k params** depending on your filter counts; a typical config (Conv1D(32, 3) → Conv1D(64, 3) → GlobalAveragePooling1D → Dense(1)) sits near **~12.9k params**.
- Training on a synthetic sinusoid + noise dataset with window=24, horizon=1 should reach **val MAE ≈ 0.04–0.08** (scaled) within **20–30 epochs**; wall clock is **~2–4 s/epoch on CPU**, **sub-second on a T4**.
- The learning curve shows train/val MAE tracking closely — a **large train–val gap (>2×)** indicates the window is too short to capture the period or the receptive field is too small.
- Predictions vs. ground truth on the test slice should track the waveform shape with a **small phase lag of 1–2 steps** — that lag is the model's conservative bias toward the last seen value, not a bug.
- If val MAE plateaus near the **naive-persistence baseline** (predict `y[t]=y[t-1]`), your 1D CNN is not learning temporal structure — increase kernel size, stack more Conv1D layers, or switch to a dilated stack.

</Callout>

<Callout type="pitfall" title="Common Pitfalls">

- **Receptive field too small** — Two Conv1D layers with kernel=3 only see 5 timesteps. If your dominant period is 24 (hourly→daily), the model physically cannot see a full cycle. Fix with **dilated convolutions** (`dilation_rate=2, 4, 8`) or larger kernels.
- **GlobalAveragePooling1D erases position** — Pooling across time collapses "when" information. For forecasting tasks that depend on recency, prefer **Flatten** (for fixed-length windows) or the **last-step slice** (`x[:, -1, :]`) before the Dense head.
- **Leaking the scaler** — Fitting `MinMaxScaler` on the full series before splitting contaminates val/test with training-distribution information. Always `fit` on train only, then `transform` val and test.
- **Causal vs. non-causal convolutions** — Default `padding="same"` uses a centered kernel, which peeks at future timesteps within the window. For strict causal forecasting, use `padding="causal"` (Conv1D supports this natively).
- **Confusing windowing stride with horizon** — Stride controls how densely you sample training windows; horizon controls how far ahead you predict. Mixing them up silently inflates your effective test-set overlap.

</Callout>

## Common Pitfalls

| Pitfall | Why It Happens | Fix |
|---|---|---|
| Receptive field too small for the dominant period | Two Conv1D(kernel=3) layers see only 5 timesteps; a 24-step daily period is outside the receptive field | Add dilated convolutions (`dilation_rate=2, 4, 8`) or increase `kernel_size` to cover at least one full dominant period |
| `GlobalAveragePooling1D` erases positional information | Averaging across all timesteps collapses the temporal structure needed for forecasting | Use `Flatten()` or slice the last timestep (`x[:, -1, :]`) before the Dense head for position-sensitive forecasting |
| Scaler fitted on the full series | Future min/max contaminates training statistics | Fit `MinMaxScaler` on training slice only; use `.transform()` on val/test |
| Default `padding="same"` leaks future within the window | Centered kernel sees future timesteps within the context window | Switch to `padding="causal"` for strictly causal convolutions |
| Confusing windowing stride with forecast horizon | Stride controls sampling density of training windows; horizon controls how far ahead to predict | Keep stride and horizon as separate arguments; do not conflate them in the window construction loop |
