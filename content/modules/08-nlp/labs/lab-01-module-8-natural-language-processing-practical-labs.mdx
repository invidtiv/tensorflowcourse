# Module 8: Natural Language Processing — Practical Labs

## Introduction

Natural language processing (NLP) has undergone three major paradigm shifts: the **symbolic era** (hand-crafted grammars, rule-based parsers, WordNet ontologies), the **statistical era** (n-gram language models, HMM/CRF taggers, TF-IDF retrieval), and the current **neural era** (distributed word embeddings, recurrent sequence models, attention-based Transformers).

This module walks you through each layer of that evolution, starting from raw text and building up to multi-head self-attention:

1. **Tokenization** (Labs 2–4) — how raw Unicode is split into discrete units: whitespace-delimited words, BPE subword pieces, or individual characters.
2. **Word embeddings** (Labs 5–6) — dense vector representations learned from co-occurrence via Skip-gram and CBOW Word2Vec.
3. **Recurrent architectures** (Labs 7–11) — sequential processing with vanilla RNN, LSTM, GRU, and bidirectional variants applied to classification, generation, and NER.
4. **Attention mechanisms** (Labs 12–14) — scaled dot-product attention, multi-head attention, and visualization of learned alignment patterns.
5. **Pretrained embeddings** (Labs 15–16) — loading GloVe and Word2Vec vectors and fine-tuning them on downstream tasks.

import tensorflow as tf
import numpy as np
from collections import Counter

# -----------------------------------------------------------
# 1. Tokenizer (replace with task-specific tokenizer)
# -----------------------------------------------------------
class SimpleTokenizer:
    """Word-level tokenizer with OOV handling."""

    def __init__(self, vocab_size=10_000, oov="<OOV>"):
        self.vocab_size = vocab_size
        self.oov = oov
        self.word2id = {}
        self.id2word = {}

    def fit(self, texts):
        counts = Counter(w for t in texts for w in t.lower().split())
        vocab = [self.oov] + [w for w, _ in counts.most_common(self.vocab_size - 1)]
        self.word2id = {w: i for i, w in enumerate(vocab)}
        self.id2word = {i: w for w, i in self.word2id.items()}

    def encode(self, text, maxlen=64, pad=True):
        ids = [self.word2id.get(w, 0) for w in text.lower().split()]
        if pad:
            ids = ids[:maxlen] + [0] * max(0, maxlen - len(ids))
        return ids


# -----------------------------------------------------------
# 2. Embedding layer
# -----------------------------------------------------------
VOCAB_SIZE  = 10_000
EMBED_DIM   = 64
SEQ_LEN     = 64

embedding_layer = tf.keras.layers.Embedding(
    input_dim=VOCAB_SIZE,
    output_dim=EMBED_DIM,
    mask_zero=True,
    name="word_embedding",
)

# -----------------------------------------------------------
# 3. Simple RNN baseline
# -----------------------------------------------------------
def build_rnn_classifier(vocab_size=VOCAB_SIZE, embed_dim=EMBED_DIM,
                          rnn_units=64, num_classes=2):
    """Minimal RNN text classifier — replace RNN cell per lab."""
    inputs = tf.keras.Input(shape=(None,), dtype=tf.int32, name="token_ids")
    x = tf.keras.layers.Embedding(vocab_size, embed_dim, mask_zero=True)(inputs)
    x = tf.keras.layers.SimpleRNN(rnn_units)(x)           # TODO: swap for LSTM / GRU / BiLSTM
    outputs = tf.keras.layers.Dense(num_classes, activation="softmax")(x)
    return tf.keras.Model(inputs, outputs, name="rnn_classifier")


model = build_rnn_classifier()
model.summary()

# -----------------------------------------------------------

## Common Pitfalls

| Pitfall | Why It Happens | Fix |
|---|---|---|
| `mask_zero=True` silently ignored by custom layers | Keras propagates the padding mask only to built-in mask-aware layers; custom `Lambda` or `Dense` layers drop it | Insert a `tf.keras.layers.Masking(mask_value=0)` before any custom layer, or call `layer.supports_masking = True` explicitly |
| Embedding `input_dim` off-by-one | Token IDs are 1-indexed (0 = pad) but `input_dim` is set to `vocab_size` rather than `vocab_size + 1` | Set `input_dim = vocab_size + 1` when using 0-based padding and 1-indexed tokens |
| Tokenizer fitted on test set | Calling `fit()` on the combined train+test corpus leaks vocabulary frequency information | Fit only on the training split; map test tokens with the training vocabulary and mark unseen words as `<OOV>` |
| `model.summary()` shows 0 parameters for Embedding | The layer was not built yet because no input shape was provided | Call `model.build(input_shape=(None, SEQ_LEN))` or pass a concrete `Input` tensor in the functional API |
| Loss does not decrease past chance on real data | Gradient clipping is missing and occasional large updates corrupt the embedding table | Always pass `clipnorm=1.0` to the optimizer when training recurrent models on text |
