# Instance Normalization

```python
"""
Lab 5.3: Instance Normalization
================================
Implement and apply instance normalization.
"""

import tensorflow as tf
import numpy as np
import matplotlib.pyplot as plt

tf.random.set_seed(42)

class InstanceNormalization(tf.keras.layers.Layer):
    """
    Instance normalization layer.
    Normalizes each sample independently across spatial dimensions.
    Commonly used in style transfer and image generation.
    """
    
    def __init__(self, epsilon=1e-5, **kwargs):
        super().__init__(**kwargs)
        self.epsilon = epsilon
    
    def build(self, input_shape):
        self.gamma = self.add_weight(name='gamma', shape=(input_shape[-1],),
                                     initializer='ones', trainable=True)
        self.beta = self.add_weight(name='beta', shape=(input_shape[-1],),
                                    initializer='zeros', trainable=True)
        super().build(input_shape)
    
    def call(self, inputs):
        mean = tf.reduce_mean(inputs, axis=[1, 2], keepdims=True)
        var = tf.reduce_variance(inputs, axis=[1, 2], keepdims=True)
        normalized = (inputs - mean) / tf.sqrt(var + self.epsilon)
        
        gamma = tf.reshape(self.gamma, [1, 1, 1, -1])
        beta = tf.reshape(self.beta, [1, 1, 1, -1])
        
        return gamma * normalized + beta
    
    def get_config(self):
        config = super().get_config()
        config.update({'epsilon': self.epsilon})
        return config

def create_style_transfer_generator():
    """Create a simple style transfer generator using instance normalization."""
    inputs = tf.keras.layers.Input(shape=(256, 256, 3))
    
    x = tf.keras.layers.Conv2D(64, 7, padding='same')(inputs)
    x = InstanceNormalization()(x)
    x = tf.keras.layers.ReLU()(x)
    
    x = tf.keras.layers.Conv2D(128, 3, strides=2, padding='same')(x)
    x = InstanceNormalization()(x)
    x = tf.keras.layers.ReLU()(x)
    
    x = tf.keras.layers.Conv2D(256, 3, strides=2, padding='same')(x)
    x = InstanceNormalization()(x)
    x = tf.keras.layers.ReLU()(x)
    
    for _ in range(5):
        residual = x
        x = tf.keras.layers.Conv2D(256, 3, padding='same')(x)
        x = InstanceNormalization()(x)
        x = tf.keras.layers.ReLU()(x)
        x = tf.keras.layers.Conv2D(256, 3, padding='same')(x)
        x = InstanceNormalization()(x)
        x = tf.keras.layers.Add()([x, residual])
    
    x = tf.keras.layers.Conv2DTranspose(128, 3, strides=2, padding='same')(x)
    x = InstanceNormalization()(x)
    x = tf.keras.layers.ReLU()(x)
    
    x = tf.keras.layers.Conv2DTranspose(64, 3, strides=2, padding='same')(x)
    x = InstanceNormalization()(x)
    x = tf.keras.layers.ReLU()(x)
    
    outputs = tf.keras.layers.Conv2D(3, 7, padding='same', activation='tanh')(x)
    
    return tf.keras.Model(inputs, outputs)

def compare_norm_for_generation():
    (x_train, y_train), (x_test, y_test) = tf.keras.datasets.cifar10.load_data()
    x_train, x_test = x_train / 255.0, x_test / 255.0
    y_train = tf.keras.utils.to_categorical(y_train, 10)
    y_test = tf.keras.utils.to_categorical(y_test, 10)
    
    def create_generator_model(norm_layer):
        inputs = tf.keras.layers.Input(shape=(32, 32, 3))
        
        x = tf.keras.layers.Conv2D(64, 3, padding='same')(inputs)
        x = norm_layer()(x) if norm_layer else x
        x = tf.keras.layers.ReLU()(x)
        
        residual = x
        x = tf.keras.layers.Conv2D(64, 3, padding='same')(x)
        x = norm_layer()(x) if norm_layer else x
        x = tf.keras.layers.ReLU()(x)
        x = tf.keras.layers.Conv2D(64, 3, padding='same')(x)
        x = norm_layer()(x) if norm_layer else x
        x = tf.keras.layers.Add()([x, residual])
        
        x = tf.keras.layers.Conv2D(3, 3, padding='same', activation='sigmoid')(x)
        
        return tf.keras.Model(inputs, x)
    
    norm_methods = {
        'Batch Norm': tf.keras.layers.BatchNormalization,
        'Instance Norm': InstanceNormalization,
        'Layer Norm': tf.keras.layers.LayerNormalization,
        'Group Norm': lambda: tf.keras.layers.GroupNormalization(groups=8),
    }
    
    results = {}
    
    for name, norm_layer in norm_methods.items():
        print(f"\nTraining with: {name}")
        
        model = create_generator_model(norm_layer)
        model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=0.001),
                      loss='mse', metrics=['accuracy'])
        
        history = model.fit(x_train, x_train, batch_size=128, epochs=10,
                           validation_data=(x_test, x_test), verbose=0)
        
        test_loss = model.evaluate(x_test, x_test, verbose=0)
        results[name] = {'history': history.history, 'test_loss': test_loss}
        print(f"  Test Loss: {test_loss:.4f}")
    
    plt.figure(figsize=(10, 6))
    for name, data in results.items():
        plt.plot(data['history']['loss'], label=name, linewidth=2)
    plt.xlabel('Epoch')
    plt.ylabel('Training Loss (MSE)')
    plt.title('Normalization Methods for Image Generation', fontweight='bold')
    plt.legend(); plt.grid(True, alpha=0.3)
    plt.savefig('instance_norm_comparison.png', dpi=150)
    plt.show()
    
    return results

results = compare_norm_for_generation()
```

## Common Pitfalls

| Pitfall | Why It Happens | Fix |
|---|---|---|
| InstanceNorm produces NaN at inference with batch=1 in TF eager mode | When a single 1×H×W feature map has zero spatial variance (e.g. all-zero activations after ReLU), dividing by `sqrt(var + epsilon)` with a near-zero numerator still returns NaN for some TF builds | Ensure `epsilon ≥ 1e-5` and add an explicit `tf.debugging.check_numerics` call during training to catch the layer early |
| Applying InstanceNorm to 1-D (Dense/sequence) features | InstanceNorm reduces over spatial axes `[1, 2]`, which only exist for 4-D tensors; calling it on a 2-D (batch, features) tensor raises a shape error | Use LayerNorm for Dense or sequence layers; reserve InstanceNorm for convolutional (spatial) layers |
| Style transfer model output looks washed out or grey | The generator output layer uses `sigmoid` but the training images were normalised to `[-1, 1]` (tanh range), causing a systematic bias | Match the activation to the data range: use `tanh` with images in `[-1, 1]` or `sigmoid` with images in `[0, 1]`; do not mix |
| Gamma and beta weights not learned (frozen at init values) | `trainable=True` was set but the layer was built inside a `tf.function` that was traced before the variables were added | Verify `layer.trainable_weights` is non-empty after the first forward pass; rebuild the model outside the traced function if needed |
| No style-transfer effect despite InstanceNorm in the network | InstanceNorm alone does not inject style — the style signal must come from adaptive parameters (AdaIN) or a style loss | For real style transfer, replace fixed gamma/beta with style-conditioned values (see Stretch Goal 1) or add a Gram-matrix perceptual loss |

## Stretch Goals

2. **Conditional Instance Normalization.** Extend the `InstanceNormalization` class to accept a class index (0–9 for CIFAR-10) and maintain a separate `(gamma, beta)` pair per class stored as a `(num_classes, channels)` `Embedding`. Compare reconstruction MSE per class against the unconditional baseline.
3. **FiLM (Feature-wise Linear Modulation).** Replace InstanceNorm in the style-transfer generator with a `FiLM` layer: given a conditioning vector `z`, predict `(gamma, beta)` with a two-layer MLP and apply `gamma * x + beta` to the normalised features. Benchmark FiLM vs AdaIN on a 10-style CIFAR-10 reconstruction task.
4. **Normalization-free baseline with weight standardisation.** Remove all normalization layers and instead apply Weight Standardisation (normalise `Conv2D` kernel weights to zero mean and unit variance before each forward pass). Compare training stability and final MSE against the InstanceNorm model to understand the trade-off between activation-space and weight-space normalisation.

# Summary and Key Takeaways

## Optimizer Comparison
- **AdamW** often achieves best generalization with proper weight decay
- **SGD with momentum** can generalize better but requires tuning
- **Adam** provides fast convergence for most tasks
- Consider task-specific requirements when choosing optimizers

## Learning Rate Scheduling
- **Cosine annealing with warmup** provides smooth convergence
- **One-cycle policy** can achieve super-convergence
- **Cyclical learning rates** help escape local minima
- Always use learning rate finder to establish good baseline

## Data Pipeline Optimization
- Use **cache()**, **prefetch()**, and **parallel map()** for speed
- **tf.data** pipelines can achieve near-optimal throughput
- Consider **distributed data loading** for multi-GPU training
- Augmentation on GPU can be faster for complex transforms

## Regularization Techniques
- **Dropout** placement matters: lower in conv layers, higher in FC
- **L1 regularization** induces sparsity; **L2** prevents overfitting
- **Early stopping** with patience prevents overfitting efficiently
- **Mixed precision** training provides ~2x speedup with minimal accuracy loss

## Normalization Layers
- **Batch Normalization** works well with larger batch sizes
- **Layer Normalization** is batch-size independent
- **Group Normalization** balances between batch and layer norm
- **Instance Normalization** excels in style transfer tasks
