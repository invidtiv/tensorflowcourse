# Custom Detector Training with TF OD API

## Objectives
- Prepare custom dataset for TF OD API
- Configure training pipeline
- Train a custom object detector
- Export trained model

## Expected Output

**Dataset preparation** (Section 1 — TFRecord creation):
```
Total images: 100
Train split: 80 images  →  train.record  (written, ~12–15 MB for 640 px images)
Val split:   20 images  →  val.record    (~3–4 MB)
Verifying 5 training examples:
  Example 0: image_id=0001, boxes=3, classes=[person, car, dog]
  ...
TFRecord creation complete.
```

**Pipeline configuration** (Section 2 — pipeline.config):
Key fields that must be set (confirm these lines are non-default in your config):
- `num_classes`: matches your label map (e.g., 3 for person/car/dog)
- `fine_tune_checkpoint`: absolute path to the pre-trained checkpoint (`.ckpt-0`)
- `fine_tune_checkpoint_type`: `"detection"` (not `"classification"`)
- `batch_size`: 4–8 for local GPU (≥32 GB RAM), 2 for CPU
- `train_input_reader.input_path` / `eval_input_reader.input_path`: paths to your `.record` files

**Training output** (Section 3 — training loop, 1 000 steps):
```
Step 100: loss = 2.45  lr = 0.0133
Step 200: loss = 1.87  lr = 0.0267
...
Step 1000: loss = 0.62  lr = 0.04
Checkpoint saved: model.ckpt-1000
```
*Total time: ~15–25 min on CPU (8-core), ~2–4 min on a single GPU (RTX 3060+).*

**Evaluation** (Section 4 — COCO metrics on val split, 1 000 steps):

| Metric | Expected range | Notes |
|--------|---------------|-------|
| mAP@[0.5:0.95] | 0.10–0.30 | 1 000 steps is under-trained; expect significant improvement by 5 000+ |
| mAP@0.5 | 0.25–0.55 | IoU@0.5 is lenient — visible recall even early |
| AR@1 | 0.05–0.15 | Average Recall, 1 detection/image |
| AR@100 | 0.20–0.40 | More detections allowed |

**Export** (Section 5 — SavedModel):
```
Exporting inference graph...
Converted 1 variables to const ops.
SavedModel written to: exported_model/saved_model/saved_model.pb
```
Inference call on a test image should return:
- `detection_boxes`: shape `(1, 100, 4)` — top-100 proposals
- `detection_scores`: shape `(1, 100)` — confidence scores
- `detection_classes`: shape `(1, 100)` — class indices (1-indexed)
- `num_detections`: shape `(1,)` — number of valid (score > threshold) detections

def create_tf_example(image_path: str,
                      boxes: List[List[float]],
                      classes: List[int],
                      image_id: int) -> tf.train.Example:
    """
    Create a TFRecord example for object detection.
    
    Args:
        image_path: Path to image file
        boxes: List of bounding boxes [x_min, y_min, x_max, y_max] (normalized)
        classes: List of class IDs
        image_id: Unique image identifier
    
    Returns:
        TFRecord Example
    """
    # Read image
    image = tf.io.read_file(image_path)
    image_shape = tf.image.decode_image(image).shape
    
    height, width = image_shape[0], image_shape[1]
    
    # Create feature dictionary
    feature = {
        'image/height': tf.train.Feature(int64_list=tf.train.Int64List(value=[height])),
        'image/width': tf.train.Feature(int64_list=tf.train.Int64List(value=[width])),
        'image/filename': tf.train.Feature(bytes_list=tf.train.BytesList(value=[image_path.encode()])),
        'image/source_id': tf.train.Feature(bytes_list=tf.train.BytesList(value=[str(image_id).encode()])),
        'image/encoded': tf.train.Feature(bytes_list=tf.train.BytesList(value=[image.numpy()])),
        'image/format': tf.train.Feature(bytes_list=tf.train.BytesList(value=[b'jpg'])),
        'image/object/bbox/xmin': tf.train.Feature(float_list=tf.train.FloatList(value=[b[0] for b in boxes])),
        'image/object/bbox/xmax': tf.train.Feature(float_list=tf.train.FloatList(value=[b[2] for b in boxes])),
        'image/object/bbox/ymin': tf.train.Feature(float_list=tf.train.FloatList(value=[b[1] for b in boxes])),
        'image/object/bbox/ymax': tf.train.Feature(float_list=tf.train.FloatList(value=[b[3] for b in boxes])),
        'image/object/class/label': tf.train.Feature(int64_list=tf.train.Int64List(value=classes)),
    }
    
    return tf.train.Example(features=tf.train.Features(feature=feature))


def create_synthetic_dataset(output_path: str,
                              num_samples: int = 100,
                              num_classes: int = 3):
    """
    Create a synthetic dataset for training demonstration.
    
    Args:
        output_path: Path to save TFRecord
        num_samples: Number of samples to generate
        num_classes: Number of object classes
    """
    print(f"Creating synthetic dataset with {num_samples} samples...")
    
    with tf.io.TFRecordWriter(output_path) as writer:
        for i in range(num_samples):
            # Generate random image
            image = np.random.randint(0, 256, (480, 640, 3), dtype=np.uint8)
            
            # Save temporary image
            temp_path = f'/tmp/synth_image_{i}.jpg'
            tf.keras.preprocessing.image.save_img(temp_path, image)
            
            # Generate random boxes
            num_boxes = np.random.randint(1, 5)
            boxes = []
            classes = []
            
            for _ in range(num_boxes):
                x_min = np.random.uniform(0, 0.7)
                y_min = np.random.uniform(0, 0.7)
                width = np.random.uniform(0.1, 0.3)
                height = np.random.uniform(0.1, 0.3)
                
                boxes.append([x_min, y_min, x_min + width, y_min + height])
                classes.append(np.random.randint(1, num_classes + 1))
            
            # Create TF example
            example = create_tf_example(temp_path, boxes, classes, i)
            writer.write(example.SerializeToString())
            
            # Clean up
            os.remove(temp_path)
    
    print(f"Dataset saved to {output_path}")

def create_label_map(class_names: List[str], output_path: str):
    """
    Create a label map file for TF OD API.
    
    Args:
        class_names: List of class names
        output_path: Path to save label map
    """
    with open(output_path, 'w') as f:
        for i, name in enumerate(class_names, 1):
            f.write(f'item {{\n')
            f.write(f'  id: {i}\n')
            f.write(f'  name: "{name}"\n')
            f.write(f'}}\n\n')
    
    print(f"Label map saved to {output_path}")


def create_label_map_pbtxt(num_classes: int = 3, output_path: str = 'label_map.pbtxt'):
    """
    Create a sample label map.
    """
    class_names = [f'object_{i}' for i in range(1, num_classes + 1)]
    create_label_map(class_names, output_path)

## Common Pitfalls

<Callout type="pitfall" title="Common Pitfalls">
- **Wrong label map IDs**: Label map IDs must start at 1, not 0. ID 0 is reserved for the background class in the TF OD API. Starting at 0 silently shifts all your class predictions by one.
- **Mismatched paths in pipeline.config**: The `fine_tune_checkpoint`, `label_map_path`, and `input_path` fields are absolute paths. If you move your project directory, training fails with cryptic `NotFoundError` messages. Use relative paths or a script that patches them at runtime.
- **Forgetting `fine_tune_checkpoint_type`**: When fine-tuning from a COCO-pretrained model, set `fine_tune_checkpoint_type: "detection"` (not `"classification"`). Using the wrong type loads only the backbone weights and discards the detection head, causing training to start from scratch on the head.
- **TFRecord field name mismatch**: The TF OD API expects specific field names (`image/encoded`, `image/object/bbox/xmin`, etc.). Custom TFRecord generation scripts often use different names, causing silent data loading failures where the model trains on images with no annotations.
- **Batch size too large for GPU memory**: The default configs from the model zoo assume multi-GPU setups. Reduce `batch_size` in `train_config` to 2–4 for single-GPU training, or you'll get OOM errors.
</Callout>

## Stretch Goals

<Callout type="tip" title="Stretch Goals">
- **End-to-end fine-tuning on a real dataset**: Download a small subset of Open Images v7, convert annotations to TFRecord, and fine-tune an EfficientDet-D0 or SSD MobileNet v2 for 5000 steps. Evaluate with `object_detection.metrics.coco_tools`.
- **Model export and TFLite conversion**: After training, export to SavedModel, then convert to TFLite with `tf.lite.TFLiteConverter`. Benchmark inference speed on CPU vs. the original SavedModel.
- **Hyperparameter sweep**: Vary learning rate warmup steps, total steps, and data augmentation options (random crop, mosaic, color jitter) in pipeline.config. Track mAP across configs to find the best setup for your dataset.
- **Custom augmentation pipeline**: Add `data_augmentation_options` blocks to pipeline.config — try `random_horizontal_flip`, `random_crop_image`, `ssd_random_crop`, and `random_adjust_brightness` to improve robustness.
</Callout>
