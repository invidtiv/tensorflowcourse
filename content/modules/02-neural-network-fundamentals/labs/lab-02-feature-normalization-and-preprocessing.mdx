## Expected Output

Comparing three scalers on a regression or classification task with features on different scales:

| Scaler | Convergence Speed | Final Val Loss | Notes |
|--------|------------------|---------------|-------|
| No scaling (raw) | Slowest — optimizer takes inconsistent step sizes | Highest | Baseline to confirm normalization is necessary |
| MinMax (range [0, 1]) | Fast | Low | Sensitive to outliers — extreme values compress the rest |
| Standard (Z-score, μ=0, σ=1) | Fast | Low | Best general-purpose choice for most datasets |
| Robust (uses IQR, ignores outliers) | Fast | Comparable to Standard | Best when the dataset contains significant outliers |
| TF `Normalization` layer | Same as Standard | Same | Layer-based approach — normalization is part of the model graph |

## Common Pitfalls

| Pitfall | Why It Happens | Fix |
|---------|----------------|-----|
| **Fitting the scaler on the full dataset before splitting** | Calling `scaler.fit(X_all)` before `train_test_split` leaks test-set statistics (mean, std, min, max) into the training pipeline, producing artificially optimistic evaluation results. | Always split first: `X_train, X_test = train_test_split(X)`, then `scaler.fit(X_train)` only. |
| **Not casting to float32 before scaling** | TensorFlow operations require `float32` by default. Passing `float64` numpy arrays causes a dtype mismatch that may silently reduce performance or raise `InvalidArgumentError` in mixed-precision training. | Add `.astype(np.float32)` after scaling: `X_train_scaled = scaler.fit_transform(X_train).astype(np.float32)`. |
| **MinMax scaler exploding on unseen test outliers** | If a test sample's feature value exceeds the training max, MinMax scaling produces a value > 1. Neural networks may not have seen these out-of-range inputs during training. | Clip after scaling: `np.clip(X_test_scaled, 0, 1)`, or prefer RobustScaler / StandardScaler for datasets with outliers. |
| **Re-fitting the scaler on the test set for evaluation** | Calling `scaler.fit_transform(X_test)` re-centers the test set around its own mean, destroying the alignment with training data and making predictions meaningless. | Use `scaler.transform(X_test)` — only `transform`, never `fit_transform`, on test data. |
| **Using `tf.keras.layers.Normalization` without calling `.adapt()`** | The `Normalization` layer initializes with mean=0, variance=1 (no-op). Without calling `layer.adapt(X_train)`, it does not normalize the data at all. | Always call `norm_layer.adapt(X_train)` before including the layer in model training. |
